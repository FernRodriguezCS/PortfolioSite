My contribution

The integration ladder

Changes move forward through the team’s development path.

  1. Feature branches Build features in isolation.
  2. THE RING Check how completed features work together.
  3. MUDPIT Make major changes in the working build.
  4. POND Handle QA and polish.
  5. MAIN Keep the stable release.
